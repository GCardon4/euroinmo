# Euro Inmobiliaria
Empresa inmobiliaria con 14 años de Experiencia, acompañando familias por sus sueños, proyecto creato en Next.js framework de React + Supabase, orientado a una arquitectura moderna, escalable y mantenible.

## Stack Tecnologico

* **Next.js**
* **React**
* **Supabase**

  * PostgreSQL
  * Authentication
  * Storage
  * Row Level Security (RLS)

## Dependencias

Listado de librerías adicionales utilizadas en el proyecto:

* `@supabase/ssr` — Integración de Supabase con Next.js
* `@supabase/supabase-js` — Cliente de Supabase
* `zustand` / `zustand` — Manejo de estado
* `zod` — Validación de datos
* `react-hook-form` — Manejo de formularios


## Desarrollo

```bash
npm install
npm run dev
```

La aplicación disponible en o servidor local configurado con sus puertos:

```text
http://localhost:3000
```
