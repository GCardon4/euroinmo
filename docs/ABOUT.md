## Stack Tecnologico

* **Next.js**
* **React**
* **Supabase**

  * PostgreSQL
  * Authentication
  * Storage
  * Row Level Security (RLS)

* **Storage Supabase**
- Politicas RLS en proyectos y propiedades habilitadas para CRUD
 * Proyectos 'projects'
 * Agentes 'agents'
 * Propiedades o Inmuebles 'properties'


## Dependencias

Listado de librerías adicionales utilizadas en el proyecto:

* `@supabase/ssr` — Integración de Supabase con Next.js
* `@supabase/supabase-js` — Cliente de Supabase
* `zustand` / `zustand` — Manejo de estado
* `zod` — Validación de datos
* `react-hook-form` — Manejo de formularios


## Desarrollo

```bash
npm install
npm run dev
```

La aplicación disponible en o servidor local configurado con sus puertos:

```text
http://localhost:3000
```
